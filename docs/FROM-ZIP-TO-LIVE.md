# از صفر تا نصب — راهنمای دقیق

این سند را دنبال کنید، خط به خط. هر جا باید دستور بزنید، دستور نوشته
شده. هر جا باید فایل عوض کنید، می‌گوید کدام خط.

نسخهٔ مرجع: **۱.۱.۰** · ۸۳ فایل در `sparkknife-ledger/` · ۷۷ فایل PHP

---

## ⚠️ اول از همه: کلید خصوصی

**کلید خصوصی لایسنس با بازنشانی محیط توسعه پاک شد.**

یعنی **این زیپ نمی‌تواند لایسنس صادر کند.** اگر همین زیپ را بفروشید،
هیچ لایسنسی کار نمی‌کند و هیچ مشتری نمی‌تواند نسخهٔ «pro» بگیرد.

خبر خوب: کاری که لازم است **۱۰ دقیقه** است و در گام ۱ انجامش می‌دهیم.

---

## گام ۰ — پیش‌نیازها

روی لپ‌تاپ یا سروری که کار می‌کنید، این‌ها را داشته باشید:

```bash
# بررسی
php -v      # باید 7.4 یا بالاتر باشد
openssl version
```

اگر `php -v` خطا داد:

| سیستم | نصب |
| --- | --- |
| Ubuntu / Debian | `sudo apt install php-cli openssl` |
| macOS | `brew install php` |
| Windows | [php.net/downloads](https://windows.php.net/download) — نسخهٔ Thread Safe، و پوشهٔ `php` را به `PATH` اضافه کنید |

روی ویندوز، `openssl` همراه PHP می‌آید. اگر `openssl` را نشناخت،
از **Git Bash** استفاده کنید که هر دو را دارد.

## گام ۱ — ساخت جفت کلید (۱۰ دقیقه)

### ۱.۱ باز کردن پوشهٔ درست

زیپ را استخراج کنید. داخلش این ساختار است:

```
SparKnife-ledger/
├── sparkknife-ledger/        ← این فولدر را روی هاست آپلود می‌کنید
├── docs/
├── tools/                    ← دستورهای زیر از همین‌جا اجرا می‌شود
├── tests/
└── package.json
```

⚠️ **مهم:** دستورهای گام ۱ را باید از **ریشهٔ زیپ** اجرا کنید (پوشه‌ای
که `tools` داخلش است)، نه از داخل `sparkknife-ledger`.

### ۱.۲ اجرای دستورها

```bash
cd tools/licensing

# کلید خصوصی — ۳۰۷۲ بیت
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:3072 -out private_key.pem

# کلید عمومی متناظر
openssl rsa -in private_key.pem -pubout -out public_key.pem

# تأیید
openssl pkey -in private_key.pem -noout -check
```

خروجی دستور آخر باید باشد:

```
Key is valid
```

اگر `Key is valid` نگرفت، **متوقف شوید** و خطا را بفرستید.

### ۱.۳ گرفتن اثر انگشت

```bash
openssl rsa -in private_key.pem -pubout 2>/dev/null | openssl dgst -sha256 -r | awk '{print $1}'
```

یک رشتهٔ ۶۴ نویسه‌ای می‌گیرید مثل `a1b2c3…`. **این را یادداشت کنید.**

### ۱.۴ جایگزینی کلید در کد — **این مهم‌ترین بخش است**

فایل را باز کنید:

```
sparkknife-ledger/includes/Core/class-sparkknife-ledger-license.php
```

خط **۷۴** را پیدا کنید. چنین چیزی می‌بینید:

```php
	const PUBLIC_KEY = '-----BEGIN PUBLIC KEY-----
MIIBojANBgkqhkiG9w0BAQEFAAOCAY8AMIIBigKCAYEAvf3JMl07YUdG9Gjtsfiy
sgqkMvTDaWGcwIcbMquHqH2S7aBYvvt3W7pRSoXGjSBO+rumJ1nIMdKFmWIMmxa9
...
Dc9/n4z9YmMIaOFNbzTEtuEiYnLINAu5d7WgDnxdvG2HAgMBAAE=
-----END PUBLIC KEY-----';
```

**کل این رشتهٔ بین دو کوتیشن را** با محتوای کامل `tools/licensing/public_key.pem`
عوض کنید. یعنی نتیجه باید شود:

```php
	const PUBLIC_KEY = '-----BEGIN PUBLIC KEY-----
کلید-تازه-شما-اینجا
-----END PUBLIC KEY-----';
```

نکته‌های ریز که اشتباه می‌شوند:

| ❌ اشتباه | ✅ درست |
| --- | --- |
| گذاشتن کلید در خطوط جدا با `"` | یک رشتهٔ تک‌کوتیشن، با `\n` واقعی داخلش |
| حذف `-----BEGIN PUBLIC KEY-----` | فقط و فقط **متن کلید** را عوض کنید |
| گذاشتن `;` داخل کوتیشن | `;` بعد از کوتیشن بسته |
| عوض کردن فقط مخزن، بدون کد | **هر دو با هم** |

ساده‌ترین راه مطمئن — یک دستور که خودش جایگزینی را انجام می‌دهد:

```bash
# از ریشهٔ زیپ اجرا کنید
php -r '
$f = "sparkknife-ledger/includes/Core/class-sparkknife-ledger-license.php";
$pem = trim(file_get_contents("tools/licensing/public_key.pem"));
$src = file_get_contents($f);
$new = preg_replace("/const PUBLIC_KEY = \x27.*?\x27;/s", "const PUBLIC_KEY = \x27" . $pem . "\x27;", $src, 1);
if ($new === $src) { echo "خطا: الگو پیدا نشد\n"; exit(1); }
file_put_contents($f, $new);
echo "کلید جایگزین شد\n";
'
```

بعد تأیید کنید:

```bash
# باید بگوید جایگزین شد ✓
php -r '
$f = "sparkknife-ledger/includes/Core/class-sparkknife-ledger-license.php";
$pem = trim(file_get_contents("tools/licensing/public_key.pem"));
$src = file_get_contents($f);
echo (strpos($src, $pem) !== false) ? "جایگزین شد ✓\n" : "جایگزین نشد ✗\n";
'
```

### ۱.۵ پشتیبان کلید خصوصی — **قبل از رفتن به گام ۲**

```bash
cat tools/licensing/private_key.pem
```

کل خروجی را **دقیقاً** کپی و در دو جا ذخیره کنید:

- [ ] گاوصندوق رمز (1Password / Bitwarden / …)
- [ ] یک USB یا پرینت داخل گاوصندوق فیزیکی

⚠️ اگر این کلید گم شود:
- همهٔ لایسنس‌هایی که صادر کرده‌اید **باطل** می‌شوند
- باید جفت تازه بسازید و به همهٔ خریداران کلید نو بدهید
- `private_key.pem` در `.gitignore` است، پس هرگز به گیت نمی‌رود

## گام ۲ — آزمون لایسنس روی سیستم خودتان (۵ دقیقه)

**این کار را قبل از آپلود انجام دهید.** اگر لایسنس کار نکند، بهتر است
اینجا بفهمید نه بعد از فروش.

### ۲.۱ صدور یک کلید آزمایشی

```bash
php tools/licensing/issue.php --domain=example.com --edition=pro --expiry=2027-12-31
```

خروجی یک رشتهٔ بلند شروع‌شده با `SPK1.` است. کپی کنید.

### ۲.۲ تأیید امضا

```bash
php tools/licensing/issue.php --verify=SPK1.کلید-کپی-شده
```

باید بگوید معتبر است و دامنه/نسخه/انقضا را نشان دهد.

### ۲.۳ اگر خطا داد

| خطا | معنا | راه‌حل |
| --- | --- | --- |
| `کلید خصوصی پیدا نشد` | گام ۱.۲ اجرا نشده | برگردید به ۱.۲ |
| `امضای لایسنس معتبر نیست` | `PUBLIC_KEY` با کلید خصوصی جفت نیست | گام ۱.۴ را دوباره انجام دهید |
| `این ابزار فقط از خط فرمان اجرا می‌شود` | از مرورگر اجرا کردید | از ترمینال اجرا کنید |

## گام ۳ — بستهٔ تازه بسازید (۲ دقیقه)

چون `PUBLIC_KEY` را عوض کردید، زیپ قبلی دیگر درست نیست. زیپ تازه بسازید:

**لینوکس / مک:**

```bash
# از ریشهٔ زیپ
rm -f sparkknife-ledger.zip
zip -qr sparkknife-ledger.zip sparkknife-ledger -x "*.git*" "*.DS_Store"
```

**ویندوز (PowerShell):**

```powershell
Compress-Archive -Path sparkknife-ledger -DestinationPath sparkknife-ledger.zip -Force
```

### تأیید بسته

```bash
# تعداد فایل — باید ۸۳ باشد
unzip -l sparkknife-ledger.zip | tail -1

# کلید خصوصی نباید داخلش باشد — باید 0 باشد
unzip -l sparkknife-ledger.zip | grep -c "private_key"
```

⚠️ اگر عدد دوم ۱ یا بیشتر بود، **متوقف شوید**. کلید خصوصی هرگز نباید
در بسته‌ای باشد که به دست مشتری می‌رسد.

### امضا (اختیاری ولی توصیه‌شده)

```bash
./tools/sign-release.sh sparkknife-ledger.zip
./tools/verify-release.sh sparkknife-ledger.zip tools/licensing/public_key.pem
```

باید بگوید `نتیجه: بسته معتبر است ✓`.

## گام ۴ — نصب روی وردپرس (۱۰ دقیقه)

### ۴.۱ چه چیزی لازم دارید

- [ ] یک سایت وردپرس — **آزمایشی**، نه سایت اصلی مشتری
- [ ] PHP 7.4 یا بالاتر (پیشنهاد ۸.۱+)
- [ ] HTTPS فعال
- [ ] دسترسی مدیر کل (Administrator)

### ۴.۲ نصب

۱. وارد پیشخوان وردپرس شوید
۲. **افزونه‌ها → افزودن → بارگذاری افزونه**
۳. `sparkknife-ledger.zip` را انتخاب کنید
۴. **اکنون نصب کن**
۵. **فعال‌سازی**

⚠️ **نه** فایل زیپ را در `wp-content/plugins` از حالت فشرده خارج
کنید و نه پوشهٔ `sparkknife-ledger` را با FTP آپلود کنید — هر دو
کار می‌کنند ولی وردپرس «به‌روزرسانی» را تشخیص نمی‌دهد. همیشه از
مسیر بارگذاری افزونه نصب کنید.

### ۴.۳ چه باید ببینید

- [ ] منوی **«دفتر حساب»** در نوار کناری سمت راست
- [ ] ویزارد راه‌اندازی چهارمرحله‌ای
- [ ] پیام «افزونه با موفقیت نصب شد»

### ۴.۴ اگر منو ظاهر نشد

| نشانه | علت | راه‌حل |
| --- | --- | --- |
| خطای «افزونه نصب نشد» | زیپ ناقص | دوباره بسازید (گام ۳) |
| منو نیست، خطایی هم نیست | تداخل افزونه | افزونه‌های دیگر را موقتاً غیرفعال کنید |
| صفحهٔ سفید | خطای PHP | `WP_DEBUG` را روشن کنید (گام ۵.۱) |
| «شما مجوز کافی ندارید» | نقش اشتباه | با حساب Administrator وارد شوید |

## گام ۵ — بررسی سلامت (۵ دقیقه)

### ۵.۱ روشن کردن نمایش خطا (اگر مشکلی هست)

در `wp-config.php`، پیش از خط `/* That's all, stop editing! */`:

```php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );
```

خطاها در `wp-content/debug.log` نوشته می‌شوند.

**پس از رفع مشکل، `WP_DEBUG` را به `false` برگردانید.**

### ۵.۲ صفحهٔ سلامت

**دفتر حساب → سلامت و امنیت**

انتظار: **۷ بررسی**. سه مورد ممکن است هشدار بدهند:

| بررسی | چرا | کار |
| --- | --- | --- |
| HTTPS | اگر سایت HTTP است | **حتماً رفع کنید** |
| پیشوند جدول | اگر `wp_` است | بی‌خطر |
| لایسنس | تا کلیدی وارد نکنید | طبیعی |

### ۵.۳ فعال‌سازی لایسنس

**دفتر حساب → لایسنس**

کلیدی که در گام ۲.۱ ساختید را وارد کنید — ولی باید برای **دامنهٔ همین
سایت** باشد، نه `example.com`.

```bash
# کلید درست برای دامنهٔ سایت خودتان
php tools/licensing/issue.php --domain=دامنه-سایت-شما.com --edition=pro --expiry=2027-12-31
```

انتظار: نسخه از `free` به `pro` تغییر کند.

### ۵.۴ اجرای سوئیت آزمون (اختیاری ولی ارزشمند)

```bash
php tests/run-tests.php /مسیر/به/wp-load.php
```

مثال واقعی:

```bash
php tests/run-tests.php /var/www/html/wp-load.php
```

انتظار در پایان:

```
همه تست‌ها موفق: ۹۹۰ مورد
```

⚠️ **روی سایت تولیدی اجرا نکنید.** آزمون داده می‌سازد و پاک می‌کند.
