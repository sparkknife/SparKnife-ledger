# از زیپ تا نصب — راهنمای گام‌به‌گام

این سند را از بالا به پایین دنبال کنید. هر دستور را **همان‌جا** بزنید
که گفته شده.

---

## گام ۱ — دانلود

### ۱.۱ آدرس درست

```
https://github.com/sparkknife/SparKnife-ledger
```

در این صفحه، شاخهٔ فعال را انتخاب کنید، بعد **Code** → **Download ZIP**.

### ۱.۲ ⚠️ مهم‌ترین نکته

صفحهٔ GitHub به‌طور پیش‌فرض شاخهٔ `main` را نشان می‌دهد. اگر زیپ را
از `main` بگیرید، ممکن است نسخهٔ قدیمی باشد.

**بعد از دانلود و استخراج، این را بررسی کنید** — در پوشهٔ استخراج‌شده
باید این‌ها را ببینید:

```
docs/
sparkknife-ledger/
tools/
```

**اگر فقط `README.md` دیدید، زیپ اشتباه است.** دوباره از شاخهٔ درست بگیرید.

### ۱.۳ بررسی سریع در ترمینال

```bash
ls
```

باید `tools` و `sparkknife-ledger` را نشان دهد. اگر نداد، ادامه ندهید.

## گام ۲ — باز کردن در VS Code

### ۲.۱ پوشه را باز کنید

VS Code را باز کنید → **File** → **Open Folder...**

پوشه‌ای که `tools` و `sparkknife-ledger` داخلش است را انتخاب کنید.

> نام پوشه معمولاً `SparKnife-ledger-<نام-شاخه>` است.

### ۲.۲ ترمینال را باز کنید

**Terminal** → **New Terminal**

پایین پنجره یک کادر باز می‌شود.

### ۲.۳ بررسی کنید Git Bash است

در آن کادر بزنید:

```bash
echo $SHELL
```

**باید چیزی شبیه `/usr/bin/bash` ببینید.**

اگر خطا داد یا `powershell` بود:

- کنار کادر ترمینال، فلش `v` را بزنید
- **Select Default Profile** → **Git Bash**
- ترمینال را ببندید (آیکن سطل زباله)
- دوباره **Terminal → New Terminal**

اگر Git Bash در فهرست نبود، [Git for Windows](https://git-scm.com/download/win)
را نصب کنید و VS Code را **کامل** ببندید و باز کنید.

### ۲.۴ بررسی مسیر

```bash
pwd
ls
```

| باید | اگر نبود |
| --- | --- |
| `pwd` مسیری که داخل پوشهٔ پروژه است | `cd` به پوشهٔ درست |
| `ls` شامل `tools` و `sparkknife-ledger` | زیپ اشتباه |

**اگر این دو درست نبود، هیچ دستور بعدی کار نمی‌کند.**

## گام ۳ — ساخت کلید (یک دستور)

از همان ترمینال:

```bash
bash tools/licensing/make-keys.sh
```

**همین. نه PHP لازم است، نه نصب چیزی.**

### ۳.۱ چه می‌کند

1. جفت کلید ۳۰۷۲ بیتی می‌سازد
2. `PUBLIC_KEY` داخل کد را عوض می‌کند
3. **تأیید می‌کند** دو کلید به هم می‌خورند
4. کلید خصوصی را چاپ می‌کند تا پشتیبان بگیرید

## گام ۴ — پشتیبان کلید (مهم‌ترین کار)

متن `-----BEGIN PRIVATE KEY-----` تا `-----END PRIVATE KEY-----` را
با موس انتخاب کنید و `Ctrl + Shift + C` بزنید.

در دو جا بگذارید:

- [ ] گاوصندوق رمز (1Password / Bitwarden)
- [ ] یک USB یا پرینت در جای امن

⚠️ اگر این کلید گم شود، همهٔ لایسنس‌هایی که فروخته‌اید باطل می‌شوند.

## گام ۵ — بستهٔ نصب بسازید

از همان ترمینال:

```bash
rm -f sparkknife-ledger.zip
zip -qr sparkknife-ledger.zip sparkknife-ledger
```

### بررسی — این را رد نکنید

```bash
unzip -l sparkknife-ledger.zip | grep -c private_key
```

**باید `0` بدهد.** اگر `1` داد، کلید خصوصی داخل بسته است — متوقف شوید.

```bash
unzip -l sparkknife-ledger.zip | tail -1
```

باید حدود `83` فایل نشان دهد.

## گام ۶ — نصب روی وردپرس

### ۶.۱ آماده‌سازی

- سایت وردپرس **آزمایشی** (نه سایت اصلی مشتری)
- PHP 7.4 یا بالاتر
- HTTPS فعال

### ۶.۲ نصب

1. پیشخوان → **افزونه‌ها** → **افزودن** → **بارگذاری افزونه**
2. `sparkknife-ledger.zip` را انتخاب کنید
3. **اکنون نصب کن** → **فعال‌سازی**

### ۶.۳ چه باید ببینید

- [ ] منوی **«دفتر حساب»** در نوار کناری
- [ ] ویزارد راه‌اندازی چهارمرحله‌ای

### ۶.۴ اگر منو نبود

در `wp-config.php` پیش از `/* That's all, stop editing! */`:

```php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );
```

خطا در `wp-content/debug.log` نوشته می‌شود.

## گام ۷ — سلامت و لایسنس

### ۷.۱ صفحهٔ سلامت

**دفتر حساب** → **سلامت و امنیت**

انتظار: **۷ بررسی**.

| بررسی | اگر هشدار داد |
| --- | --- |
| HTTPS | **حتماً رفع کنید** |
| پیشوند جدول | بی‌خطر |
| لایسنس | طبیعی تا کلید ندهید |

### ۷.۲ لایسنس

اگر PHP دارید:

```bash
php tools/licensing/issue.php --domain=دامنه-سایت-شما.com --edition=pro --expiry=2027-12-31
```

کلید `SPK1.xxx.yyy` را در **دفتر حساب → لایسنس** بچسبانید.

انتظار: نسخه از `free` به `pro` عوض شود.

اگر PHP ندارید، فعلاً از این مرحله بگذرید — افزونه به‌صورت `free`
کار می‌کند. برای فروش نسخهٔ `pro` بعداً باید PHP نصب کنید.
