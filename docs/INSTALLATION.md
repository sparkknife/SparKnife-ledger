## نصب

### روش ۱: بارگذاری ZIP از پنل

1. به **افزونه‌ها ← افزودن** بروید.
2. روی **بارگذاری افزونه** کلیک کنید.
3. فایل `sparkknife-ledger.zip` را انتخاب کنید.
4. **هم‌اکنون نصب کن** را بزنید.
5. **فعال کردن** را بزنید.

### روش ۲: FTP / SSH

```bash
cd wp-content/plugins
unzip sparkknife-ledger.zip
```

سپس از **افزونه‌ها** فعال کنید.

### روش ۳: WP-CLI

```bash
wp plugin install sparkknife-ledger.zip --activate
```

### چه چیزی هنگام فعال‌سازی ساخته می‌شود؟

- سه جدول با پیشوند سایت (`wp_sparkknife_ledger_persons`, `…_transactions`, `…_audit_log`)
- گزینه `sparkknife_ledger_settings` با ۱۶ مقدار پیش‌فرض
- گزینه‌های `sparkknife_ledger_db_version` و `sparkknife_ledger_version`
- هفت Capability روی نقش `administrator`

هیچ فایل تنظیمی تغییر نمی‌کند و نیازی به دسترسی نوشتن روی فایل‌ها نیست.

## تنظیمات

**دفتر حساب ← تنظیمات**، پنج تب دارد.

### واحد پول

| تنظیم | پیش‌فرض | توضیح |
| --- | --- | --- |
| نوع واحد | تومان | تومان، ریال یا دلخواه |
| نماد دلخواه | — | فقط در حالت «دلخواه» |
| برچسب دلخواه | — | مثلاً `یورو` |
| تعداد اعشار | ۰ | ۰ تا ۴ |
| جایگاه نماد | پسوند | پیشوند یا پسوند |
| جداکننده هزارگان | `,` | `,` یا `٬` |

> با `تعداد اعشار = 2`، مبلغ `15000` به‌صورت `۱.۵ تومان` نمایش داده می‌شود (ذخیره‌سازی همیشه دقیق است).

> **نکته:** نقطه در واحد بدون اعشار جداکننده هزارگان است (`1.500` یعنی
> ۱۵۰۰ تومان) و در واحد اعشاری، اعشار (`1.500` یعنی ۱.۵ دلار). این
> رفتار خودکار بر اساس «تعداد اعشار» تعیین می‌شود.

### نمایش

| تنظیم | پیش‌فرض |
| --- | --- |
| تقویم | شمسی |
| ارقام فارسی | فعال |
| تعداد آیتم در هر صفحه | ۲۰ |
| نمایش پنل خوش‌آمدگویی | فعال |

### عمومی

| تنظیم | پیش‌فرض | توضیح |
| --- | --- | --- |
| پیشوند شماره سند | `TXN` | `TXN-1403-0001` |
| دلیل الزامی برای ابطال | فعال | |
| اجازه حذف شخص | فعال | |
| نوع پیش‌فرض تراکنش | ورودی | |

### دسترسی‌ها

ماتریس نقش × Capability. تیک بزنید و ذخیره کنید. نقش `administrator` همیشه همه دسترسی‌ها را دارد.

### اگر سایت پشت پروکسی یا CDN است

IP کاربر در لاگ ممیزی از `REMOTE_ADDR` خوانده می‌شود. اگر سایت پشت
Cloudflare، لودبالانسر یا هر پروکسی دیگری باشد، این آدرس، آدرس پروکسی
است نه کاربر.

برای خواندن IP واقعی از هدر `X-Forwarded-For`، این خط را به
`wp-config.php` اضافه کنید (پیش از خط `/* That's all, stop editing! */`):

```php
define( 'SPARKKNIFE_LEDGER_TRUST_PROXY', true );
```

یا در فایل `functions.php` قالب:

```php
add_filter( 'sparkknife_ledger_trust_proxy', '__return_true' );
```

> **چرا پیش‌فرض خاموش است؟** هر کاربری می‌تواند این هدر را بفرستد. اگر
> سایت پشت پروکسی نیست و هدر را قبول کنیم، کاربر می‌تواند IP دلخواهی در
> لاگ ثبت کند و ارزش اثباتی لاگ از بین می‌رود. فقط وقتی روشنش کنید که
> مطمئنید ترافیک واقعاً از پروکسی می‌آید.

### داده‌ها

| گزینه | اثر |
| --- | --- |
| حذف داده‌ها هنگام حذف افزونه | اگر روشن باشد، حذف افزونه همه جداول و تنظیمات را پاک می‌کند |
| حذف کامل داده‌ها | پاک‌سازی فوری و برگشت‌ناپذیر — نیازمند تایپ عبارت `DELETE-ALL-DATA` |

> **هشدار:** «حذف کامل داده‌ها» بلافاصله اجرا می‌شود و قابل بازگشت نیست. پیش از آن پشتیبان بگیرید.

## اشخاص

**دفتر حساب ← اشخاص**

### افزودن

| فیلد | الزامی | توضیح |
| --- | --- | --- |
| نام | ✓ | یکتا میان اشخاص فعال |
| تلفن | — | |
| توضیحات | — | |
| وضعیت | — | فعال / غیرفعال |

### ستون‌های فهرست

نام، تلفن، وضعیت، مانده، وضعیت حساب، تاریخ ایجاد، عملیات.

**وضعیت حساب:**

| نشان | معنا |
| --- | --- |
| بستانکار | جمع ورودی > جمع خروجی (شما به این شخص بدهکارید) |
| بدهکار | جمع خروجی > جمع ورودی |
| تسویه | مانده صفر |

### جستجو و فیلتر

- جستجوی نام و تلفن
- فیلتر وضعیت (فعال / غیرفعال)
- نمایش اشخاص حذف‌شده (برای بازگردانی)
- مرتب‌سازی بر اساس نام، مانده یا تاریخ

### غیرفعال‌سازی

شخص غیرفعال از فهرست پیش‌فرض حذف می‌شود اما تراکنش‌هایش سر جای خود می‌مانند و در گزارش‌ها می‌آید. برای پایان همکاری از این گزینه استفاده کنید.

### حذف

حذف **نرم** است: ردیف می‌ماند، `deleted_at` پر می‌شود و شخص از محاسبات خارج می‌گردد. با فیلتر «حذف‌شده‌ها» قابل بازگردانی است.

حذف شخصی که تراکنش دارد مسدود است. اگر واقعاً می‌خواهید، اول تراکنش‌ها را ابطال یا جابه‌جا کنید.

### ورود مبلغ

هر سه شکل پذیرفته است:

```
1250000        →  ۱,۲۵۰,۰۰۰ تومان
1,250,000      →  ۱,۲۵۰,۰۰۰ تومان
۱٬۲۵۰٬۰۰۰      →  ۱,۲۵۰,۰۰۰ تومان
```

### شماره سند

آغاز با پیشوند تنظیمات و شامل سال و شماره ترتیبی: `TXN-1403-0001`. یکتاست؛ برای تولید سفارشی از فیلتر `sparkknife_ledger_generate_reference` استفاده کنید.

### ویرایش

هر تراکنش `posted` قابل ویرایش است. تغییرات در تاریخچه با مقادیر قبل و بعد ثبت می‌شود.

## ابطال

ابطال، جای حذف را می‌گیرد.

### چرا ابطال به‌جای حذف؟

در حسابداری، سند ثبت‌شده پاک نمی‌شود. ابطال، سند را در تاریخچه نگه می‌دارد، دلیلش را ثبت می‌کند و فقط از محاسبات کنار می‌گذارد.

### گام‌ها

1. در فهرست تراکنش‌ها، روی **ابطال** کلیک کنید.
2. دلیل را بنویسید (حداقل ۳ نویسه؛ اگر الزام را در تنظیمات خاموش کرده‌اید، اختیاری است).
3. تأیید کنید.

### پس از ابطال

- وضعیت `void` می‌شود و مبلغ از مانده شخص خارج می‌گردد
- ردیف در دیتابیس می‌ماند
- ویرایش تراکنش باطل ممکن نیست
- در تاریخچه تغییرات ثبت می‌شود

## گزارش‌ها

### گزارش فردی

**دفتر حساب ← گزارش فردی**

شخص را انتخاب کنید و بازه را تعیین کنید. خروجی شامل خلاصه (جمع ورودی، جمع خروجی، مانده) و فهرست تراکنش‌هاست.

| فیلتر | توضیح |
| --- | --- |
| بازه | امروز، این هفته، این ماه، امسال، سفارشی، همه |
| از تاریخ / تا تاریخ | در حالت سفارشی |
| نوع | همه / ورودی / خروجی |
| وضعیت | همه / ثبت‌شده / باطل |

### گزارش تجمیعی

همه اشخاص در یک جدول: جمع ورودی، جمع خروجی و مانده هر شخص، به‌همراه جمع کل.

### خروجی

**CSV / Excel** — فایل با BOM UTF-8، سازگار با Excel فارسی. ارقام به‌صورت رشته متنی نوشته می‌شوند تا Excel آن‌ها را به عدد نمایی تبدیل نکند.

**چاپ / PDF** — نمای چاپی راست‌به‌چپ در پنجره جدید. با `Ctrl+P` به PDF ذخیره کنید. حداکثر ۵۰۰ ردیف.

## حذف افزونه

### حالت پیش‌فرض (حفظ داده)

با غیرفعال و حذف افزونه:

- ✅ جداول و همه تراکنش‌ها می‌مانند
- ✅ تنظیمات می‌مانند
- ✅ Capabilityها می‌مانند
- ❌ فقط گزینه‌های نسخه حذف می‌شوند

نصب مجدد، همه‌چیز را دقیقاً به حالت قبل برمی‌گرداند.

### حالت حذف کامل

گزینه **حذف داده‌ها هنگام حذف افزونه** را در تنظیمات ← داده‌ها روشن کنید. سپس با حذف افزونه:

- جداول سه‌گانه DROP می‌شوند
- همه گزینه‌های افزونه حذف می‌شوند
- Capabilityها از همه نقش‌ها برداشته می‌شوند
- ترنزینت‌های `_transient_sparkknife_ledger_*` پاک می‌شوند

در حالت چندسایتی، این کار برای همه سایت‌ها انجام می‌شود.

### بازنویسی با کد

```php
// حتی با روشن بودن تنظیمات، داده‌ها را نگه دار
add_filter( 'sparkknife_ledger_uninstall_delete_data', '__return_false' );
```

## رفع اشکال

### منو ظاهر نمی‌شود

Capability کاربر را بررسی کنید:

```bash
wp user get admin --field=roles
wp cap list administrator | grep sparkknife
```

اگر خالی است:

```bash
wp eval 'Sparkknife_Ledger_Capabilities::add_capabilities();'
```

### خطای «جدول یافت نشد»

جداول را بازسازی کنید:

```bash
wp eval 'Sparkknife_Ledger_Installer::create_tables();'
```

یا افزونه را غیرفعال و دوباره فعال کنید.

### تاریخ شمسی ذخیره نمی‌شود

قالب پذیرفته‌شده: `۱۴۰۳/۰۵/۱۲` یا `1403/05/12`. جداکننده `/` یا `-`. روز و ماه دو رقمی توصیه می‌شود.

### مبلغ اشتباه نمایش داده می‌شود

ترتیب بررسی:

1. **تنظیمات ← واحد پول** — تعداد اعشار و جایگاه نماد
2. مقدار ذخیره‌شده را در دیتابیس ببینید:
   ```bash
   wp db query "SELECT id, amount FROM wp_sparkknife_ledger_transactions LIMIT 5;"
   ```
   مبلغ خام = مبلغ واقعی × ۱۰٬۰۰۰. اگر `250000` می‌بینید یعنی ۲۵ تومان ذخیره شده، نه ۲۵۰,۰۰۰.

### خروجی CSV در Excel به‌هم‌ریخته است

- فایل را با **Data ← From Text/CSV** باز کنید و کدگذاری را `UTF-8` بگذارید.
- Excel نسخه ۲۰۱۶ به بعد BOM را خودکار تشخیص می‌دهد.

### خطای «مبلغ بیش از حد بزرگ است»

سقف پیش‌فرض از فیلتر `sparkknife_ledger_max_amount` قابل تغییر است:

```php
add_filter( 'sparkknife_ledger_max_amount', fn() => '9000000000000000' );
```

### اطلاعات بیشتر برای گزارش باگ

```bash
wp eval 'print_r( Sparkknife_Ledger_Installer::get_health_report() );'
```

خروجی شامل وضعیت هر جدول، تعداد ردیف‌ها و نسخه اسکیماست.
