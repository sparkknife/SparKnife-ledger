# راهنمای خریدار

راهنمای نصب و فعال‌سازی **SparKnife Ledger** برای کسی که افزونه را
خریده است. اگر می‌خواهید از صفر نصب کنید و افزونه را بشناسید،
[INSTALLATION.md](INSTALLATION.md) را بخوانید. این سند کوتاه‌تر است و
فقط مسیر فروش را می‌پوشاند.

## ۱. چه چیزی دریافت کرده‌اید

در بستهٔ خرید این‌ها هست:

| فایل | توضیح |
| --- | --- |
| `sparkknife-ledger.zip` | بستهٔ افزونه، آمادهٔ نصب از پنل وردپرس |
| `کلید لایسنس` | متنی که با `SPK1.` شروع می‌شود، در ایمیل خرید |
| `راهنمای خریدار` | همین فایل |

سندهای دیگر (`ARCHITECTURE.md`، `AUDIT.md`) برای توسعه‌دهنده است و
لازم نیست بخوانید.

> **اگر کلید لایسنس را پیدا نمی‌کنید**، ابتدا پوشهٔ هرزنامهٔ ایمیل را
> ببینید. کلید یک رشتهٔ بلند تک‌خطی است و ممکن است در ایمیل شکسته
> نمایش داده شود؛ آن را از فایل پیوست یا متن کامل کپی کنید، نه از
> پیش‌نمایش ایمیل.

## ۲. پیش‌نیازها

| مورد | حداقل | چرا |
| --- | --- | --- |
| WordPress | ۵.۸ | نسخهٔ قدیمی‌تر پشتیبانی نمی‌شود |
| PHP | ۷.۴ | ۸.۱ یا بالاتر توصیه می‌شود |
| افزونهٔ OpenSSL برای PHP | فعال | برای بررسی امضای لایسنس |
| HTTPS | توصیهٔ جدی | دادهٔ مالی روی HTTP منتقل نشود |

OpenSSL تقریباً روی همهٔ هاست‌های اشتراکی فعال است. اگر نبود، افزونه
کار می‌کند ولی لایسنس بررسی نمی‌شود. برای اطمینان، پس از نصب به
صفحهٔ **سلامت و امنیت** بروید (بخش ۶).

## ۳. نصب

### روش الف: از پنل وردپرس (توصیه‌شده)

۱. وارد پنل شوید: `wp-admin`
۲. **افزونه‌ها ← افزودن ← بارگذاری افزونه**
۳. فایل `sparkknife-ledger.zip` را انتخاب و **اکنون نصب کن** را بزنید
۴. **فعال کردن** را بزنید

### روش ب: با FTP

اگر بارگذاری فایل در پنل محدود است:

۱. فایل zip را باز کنید
۲. پوشهٔ `sparkknife-ledger` را در `wp-content/plugins/` بگذارید
۳. در پنل، **افزونه‌ها** را باز کنید و افزونه را فعال کنید

### روش ج: با WP-CLI

```bash
wp plugin install sparkknife-ledger.zip --activate
```

پس از فعال‌سازی، منوی **دفتر حساب** در نوار کناری ظاهر می‌شود.

## ۴. راه‌اندازی اولیه

پس از فعال‌سازی، اگر سایت هیچ داده‌ای نداشته باشد، وردپرس شما را
خودکار به ویزارد راه‌اندازی می‌برد. چهار مرحله دارد و کمتر از یک
دقیقه طول می‌کشد:

| مرحله | چه می‌پرسد | اجباری؟ |
| --- | --- | --- |
| ۱ | خوش‌آمد و توضیح | — |
| ۲ | واحد پول (تومان/ریال/دلخواه) و تقویم (شمسی/میلادی) | بله |
| ۳ | نام اولین شخص | خیر، می‌توان رد کرد |
| ۴ | پایان و رفتن به پنل | — |

**می‌توانید کل ویزارد را رد کنید.** دکمهٔ «رد کردن و رفتن به پنل» در
مرحلهٔ ۱ هست. بعداً همه‌چیز از بخش **تنظیمات** قابل تغییر است.

> اگر ویزارد را ندیدید، یعنی سایت از قبل داده داشته یا مدیر دیگری
> آن را رد کرده است. مشکلی نیست — مستقیم به **دفتر حساب** بروید.

## ۵. فعال‌سازی لایسنس

۱. به **دفتر حساب ← سلامت و امنیت** بروید
۲. در بخش **لایسنس**، کلید را در کادر بچسبانید
۳. **فعال‌سازی لایسنس** را بزنید

### اگر پیام خطا گرفتید

| پیام | معنا | کار شما |
| --- | --- | --- |
| «این لایسنس برای دامنهٔ ... صادر شده» | کلید برای سایت دیگری است | کلیدِ دامنهٔ درست را وارد کنید |
| «لایسنس منقضی شده است» | تاریخ انقضا گذشته | با فروشنده تماس بگیرید |
| «امضای لایسنس معتبر نیست» | کلید ناقص کپی شده یا دستکاری شده | کلید را کامل و دوباره کپی کنید |
| «نسخهٔ لایسنس شناخته نشد» | کلید برای محصول دیگری است | کلید درست را بگیرید |
| «کلید لایسنس خالی است» | کادر خالی مانده | کلید را بچسبانید |

### نکته‌های مهم

- **یک بار کافی است.** کلید در دیتابیس ذخیره می‌شود و بررسی امضا
  شش ساعت کش می‌شود.
- **بدون تماس با سرور کار می‌کند.** افزونه به اینترنت وصل نمی‌شود.
  اگر سرور فروشنده در دسترس نباشد، افزونهٔ شما کار می‌کند.
- **`www` مشکلی نیست.** اگر برای `example.com` خریده‌اید، روی
  `www.example.com` هم کار می‌کند.
- **کلید نامعتبر ذخیره نمی‌شود.** اگر خطا دیدید، لایسنس قبلی دست
  نخورده است.

## ۶. بررسی سلامت

**دفتر حساب ← سلامت و امنیت** هفت بررسی می‌کند و برای هر کدام
می‌گوید چرا مهم است:

| بررسی | چه می‌گوید |
| --- | --- |
| HTTPS | آیا داده روی شبکهٔ رمزنگاری‌شده منتقل می‌شود |
| نسخهٔ PHP | آیا نسخهٔ PHP سایت به‌روز است |
| OpenSSL | آیا بررسی لایسنس کار می‌کند |
| پوشهٔ آپلود | آیا گرفتن پشتیبان ممکن است |
| نمایش خطای دیتابیس | آیا ساختار جدول‌ها به کاربر لو می‌رود |
| لایسنس | وضعیت فعال‌سازی |
| پیشوند جدول | آیا پیشوند پیش‌فرض وردپرس است |

**قبل از استفادهٔ واقعی، همه باید «سالم» باشند.** اگر «توجه» دیدید،
توضیح زیرش می‌گوید چه کار کنید.

### گزارش رویدادهای امنیتی

پایین همان صفحه، آخرین رویدادهای حساس را می‌بینید: لایسنس فعال شد،
چه کسی چند بار تلاش کرد، چه چیزی رد شد. اگر چیز عجیبی دیدید — مثلاً
ده‌ها «rate_limited» پشت‌سرهم — یعنی کسی دارد تلاش می‌کند.

گزارش را می‌توانید پاک کنید. ۱۰۰ رویداد آخر نگه داشته می‌شود.

## ۷. انتقال به سایت دیگر

کلید لایسنس به دامنه بسته است. اگر سایت را جابه‌جا می‌کنید:

۱. روی سایت قدیم، **سلامت و امنیت ← حذف لایسنس از این سایت**
۲. با فروشنده تماس بگیرید و دامنهٔ جدید را اعلام کنید
۳. کلید جدید را روی سایت جدید وارد کنید

> **کلید را خودتان برای دامنهٔ دیگر دستکاری نکنید.** امضا با تغییر
> هر حرفی باطل می‌شود و کلید رد خواهد شد.

اگر سایت را از `example.com` به `www.example.com` منتقل می‌کنید،
نیازی به کلید جدید نیست.

## ۸. پشتیبان‌گیری

**قبل از هر عملیات حساس، پشتیبان بگیرید.** دو عملیات برگشت‌ناپذیرند:

- **پاک‌سازی داده** در تنظیمات (همهٔ اشخاص و تراکنش‌ها را حذف می‌کند)
- **حذف افزونه با پاک‌سازی داده** (اگر فیلتر فعال باشد)

پشتیبان از دو جا:

۱. پشتیبان دیتابیس هاست (بیشتر هاست‌ها ابزار خودکار دارند)
۲. پشتیبان‌گیری وردپرس از **ابزارها ← خروجی گرفتن**

> افزونهٔ خودش پشتیبان نمی‌گیرد. این عمدی است: پشتیبان‌گیری وظیفهٔ
> هاست است و افزونه‌ای که از خودش پشتیبان می‌گیرد، معمولاً بد
> پشتیبان می‌گیرد.

## ۹. رفع اشکال

### منوی «دفتر حساب» را نمی‌بینم

- افزونه فعال است؟ **افزونه‌ها** را چک کنید.
- نقش شما Administrator است؟ نقش‌های دیگر باید از **دسترسی‌ها**
  مجوز بگیرند.

### ویزارد نشان داده نمی‌شود

طبیعی است اگر سایت داده دارد. مستقیم به **دفتر حساب** بروید. برای
دیدن دوباره:

```bash
wp option delete sparkknife_ledger_onboarding_done
```

### لایسنس فعال نمی‌شود

۱. کلید را کامل کپی کرده‌اید؟ (شروع با `SPK1.`، سه بخش جدا با نقطه)
۲. دامنهٔ سایت را با **تنظیمات ← عمومی ← نشانی سایت** مقایسه کنید
۳. به **سلامت و امنیت** بروید و ببینید OpenSSL «سالم» است یا نه
۴. اگر OpenSSL نبود، با هاست تماس بگیرید

### صفحهٔ سلامت خطای دسترسی می‌دهد

این صفحه فقط برای Administrator است. اگر نقش دیگری دارید، از مدیر
کل بخواهید.

### «تعداد تلاش‌ها بیش از حد مجاز است»

نگهبان امنیتی جلوی تکرار پشت‌سرهم یک عملیات حساس را گرفته است. چند
دقیقه صبر کنید. اگر خودتان پشت‌سرهم کلیک کردید، این طبیعی است.

## ۱۰. پشتیبانی

هنگام تماس این‌ها را بفرستید تا سریع‌تر حل شود:

۱. نسخهٔ وردپرس و PHP (در **سلامت و امنیت** دیده می‌شود)
۲. نسخهٔ افزونه (در **افزونه‌ها**)
۳. متن دقیق پیام خطا
۴. کاری که می‌کردید وقتی خطا آمد

**کلید لایسنس را در تیکت عمومی نگذارید** — کافی است بگویید برای کدام
دامنه صادر شده. کلید مثل رمز است.
