# راهنمای نصب آزمایشی و پشتیبان‌گیری

راهنمای گام‌به‌گام برای اینکه افزونه را **بدون ریسک** روی سایت واقعی خود آزمایش کنید.

---

## اول: پشتیبان‌گیری یعنی چه و چطور؟

قبل از هر کاری، از دیتابیس پشتیبان بگیرید. پشتیبان یعنی یک **کپی کامل** از همه داده‌های سایت، در یک فایل. اگر چیزی خراب شد، آن فایل را برمی‌گردانید و سایت دقیقاً به حالت قبل برمی‌گردد.

سه راه دارد. **فقط یکی** را انتخاب کنید — بستگی دارد به اینکه به چه چیزی دسترسی دارید.

### راه ۱ — افزونه (ساده‌ترین، بدون SSH)

اگر نمی‌دانید SSH چیست، از این راه بروید:

1. در پنل وردپرس: **افزونه‌ها ← افزودن** → جستجو کنید `UpdraftPlus`
2. نصب و فعال کنید
3. **تنظیمات ← UpdraftPlus Backups** → دکمه **Backup Now** را بزنید
4. فقط **Database** را تیک بزنید → **Backup Now**
5. فایل `.sql` یا `.gz` را روی کامپیوتر خودتان دانلود کنید

برای برگرداندن: همان صفحه → **Existing backups** → **Restore** → انتخاب دیتابیس.

### راه ۲ — پنل هاست (اگر cPanel/DirectAdmin دارید)

1. وارد پنل هاست شوید (آدرس و رمز را از شرکت هاستینگ بگیرید)
2. دنبال یکی از این‌ها بگردید:
   - **Backup** یا **Backup Wizard**
   - **phpMyAdmin** → پایگاه‌داده خود را انتخاب کنید → تب **Export** → **Go**
3. فایل دانلودشده را نگه دارید

### راه ۳ — WP-CLI (اگر به SSH دسترسی دارید)

```bash
wp db export backup-before-ledger.sql
```

این دستور کل دیتابیس را در فایل `backup-before-ledger.sql` می‌ریزد. تمام.

برای برگرداندن:

```bash
wp db import backup-before-ledger.sql
```

> **`wp` چطور نصب می‌شود؟** روی بیشتر هاست‌های اشتراکی از قبل نصب است. اگر نبود، در مسیر سایت بزنید:
> ```bash
> curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar
> chmod +x wp-cli.phar
> ./wp-cli.phar db export backup.sql --path=/path/to/public_html
> ```

## دوم: نصب آزمایشی

### روش الف — سایت آزمایشی کامل (امن‌ترین)

این روش را فقط یک‌بار تنظیم می‌کنید و بعد از آن هر افزونه‌ای را بی‌خطر امتحان می‌کنید.

#### گزینه ۱: LocalWP (روی کامپیوتر خودتان، کاملاً آفلاین)

1. از `localwp.com` نسخه رایگان را دانلود و نصب کنید
2. **Create a new site** → نامی بدهید
3. **Preferred** را انتخاب کنید (Apache + PHP + MySQL)
4. روی **Start site** کلیک کنید و منتظر بمانید
5. **WP Admin** را بزنید → با اکانت ادمین وارد شوید
6. **افزونه‌ها ← افزودن ← بارگذاری افزونه** → `sparkknife-ledger.zip` → نصب → فعال

**مزیت:** کاملاً روی سیستم شماست، هیچ ریسکی برای سایت اصلی ندارد. برای تست افزونه‌ها بهترین گزینه است.

#### گزینه ۲: زیرپوشه روی خود هاست (اگر LocalWP ندارید)

1. از پنل هاست، یک دیتابیس جدید بسازید (نام و کاربر بسازید)
2. در **File Manager** یک پوشه `test` بسازید → `public_html/test`
3. وردپرس را در آن نصب کنید (فایل `wordpress.zip` از wordpress.org)
4. **افزونه‌ها ← افزودن ← بارگذاری** → `sparkknife-ledger.zip`

**نکته:** دو سایت در یک هاست = منابع مشترک. اگر ترافیک سایت اصلی بالاست، ممکن است کند شود.

#### گزینه ۳: سرویس آنلاین (سریع‌ترین)

سرویس‌هایی مثل **InstaWP** یک سایت وردپرس موقت می‌دهند که در مرورگر باز می‌شود — بدون نیاز به نصب چیزی. برای تست سریع عالی است.

---

### روش ب — نصب مستقیم روی سایت خودتان (با احتیاط)

اگر سایتتان کوچک است و نمی‌خواهید سایت آزمایشی بسازید:

1. **پشتیبان بگیرید** (بخش اول همین راهنما)
2. افزونه را در ساعت کم‌ترافیک نصب کنید
3. **فوراً** این چک‌لیست را اجرا کنید
4. اگر هر مشکلی دیدید → غیرفعال کنید، پشتیبان را برگردانید

## چک‌لیست پس از نصب

این ده مورد را به ترتیب انجام دهید. اگر همه پاس شدند، افزونه درست کار می‌کند.

### ۱. منو ظاهر شد؟

**دفتر حساب** در نوار کناری پنل وردپرس. اگر نیست، دسترسی کاربر را بررسی کنید.

### ۲. جداول ساخته شدند؟

اگر SSH دارید:

```bash
wp db query "SHOW TABLES LIKE '%sparkknife%';"
```

باید **سه جدول** ببینید:

```
wp_sparkknife_ledger_persons
wp_sparkknife_ledger_transactions
wp_sparkknife_ledger_audit_log
```

بدون SSH: **تنظیمات ← داده‌ها** را باز کنید — باید وضعیت جداول را نشان دهد.

### ۳. یک شخص بسازید

**دفتر حساب ← اشخاص** → نامی فارسی مثل `تست` و شماره `09120000000` → ذخیره.

✅ باید در فهرست ظاهر شود.

### ۴. یک تراکنش ثبت کنید

**دفتر حساب ← تراکنش‌ها ← افزودن** → شخص را انتخاب کنید، مبلغ `1000000` (یک میلیون)، تاریخ امروز → ثبت.

✅ باید ثبت شود و مانده شخص یک میلیون شود.

### ۵. ارقام فارسی را امتحان کنید

یک تراکنش دیگر با مبلغ `۱٬۲۵۰٬۰۰۰` (با ارقام فارسی و جداکننده) ثبت کنید.

✅ باید به همان یک میلیون و دویست و پنجاه هزار تبدیل شود.

### ۶. ابطال را امتحان کنید

روی تراکنش اول، **ابطال** → دلیل را بنویسید → تأیید.

✅ باید مبلغ از مانده کم شود ولی ردیف بماند (فیلتر «باطل‌شده‌ها»).

### ۷. تنظیمات را ذخیره کنید و **همه تب‌ها را برگردید**

این مهم‌ترین آزمون است. باگ مهمی که در ممیزی پیدا شد اینجا لو می‌رود:

1. **تنظیمات ← واحد پول** → واحد را به «ریال» تغییر دهید → ذخیره
2. **تنظیمات ← عمومی** → بررسی کنید **«ثبت دلیل ابطال الزامی باشد» هنوز تیک دارد**
3. **تنظیمات ← نمایش** → بررسی کنید **«ارقام فارسی» هنوز تیک دارد**

✅ اگر هر کدام بی‌دلیل خاموش شده بود، باگ وجود دارد.

### ۸. گزارش و خروجی

**دفتر حساب ← گزارش فردی** → شخص تست را انتخاب کنید → **خروجی CSV**.

✅ فایل باید در Excel باز شود و حروف فارسی درست نمایش داده شوند (نه علامت سؤال).

### ۹. چاپ

در همان گزارش، **چاپ / PDF** را بزنید.

✅ پنجره چاپ مرورگر باید باز شود، راست‌به‌چپ و با فونت فارسی.

### ۱۰. حذف نکنید، فقط غیرفعال کنید

اگر می‌خواهید آزمایش را متوقف کنید، **غیرفعال** کنید (نه حذف). حذف هم در حالت پیش‌فرض داده‌ها را نگه می‌دارد، ولی غیرفعال کردن امن‌تر است.

## اگر مشکلی پیش آمد

### افزونه فعال نمی‌شود

خطا را ببینید. `wp-content/debug.log` را باز کنید (اگر `WP_DEBUG` روشن است).

برای برگرداندن فوری:

```bash
wp db import backup-before-ledger.sql
wp plugin deactivate sparkknife-ledger
```

بدون SSH: پوشه `sparkknife-ledger` را از `wp-content/plugins/` با File Manager حذف/تغییرنام دهید.

### صفحه سفید شد

معمولاً یعنی خطای PHP. از پنل هاست پوشه افزونه را تغییرنام دهید به `sparkknife-ledger-off` — وردپرس خودش آن را غیرفعال می‌کند.

### «جدول یافت نشد»

اگر SSH دارید:

```bash
wp eval 'Sparkknife_Ledger_Installer::create_tables();'
```

یا افزونه را غیرفعال و دوباره فعال کنید.

### داده‌ها را کامل پاک کردم، چطور برگردانم؟

```bash
wp db import backup-before-ledger.sql
```

این تنها راه است. **به همین دلیل پشتیبان‌گیری مهم است.**

---

## پس از موفقیت در آزمایش

1. روی سایت اصلی پشتیبان بگیرید
2. افزونه را نصب و فعال کنید
3. چک‌لیست بالا را یک‌بار دیگر اجرا کنید
4. اگر داده‌ی آزمایشی ساختید، پاکشان کنید: **تنظیمات ← داده‌ها ← حذف کامل داده‌ها** (نیازمند تایپ `DELETE-ALL-DATA`)

---

## خلاصه در سه خط

```bash
# ۱) پشتیبان
wp db export backup.sql

# ۲) نصب (یا از پنل: افزونه‌ها ← بارگذاری)
wp plugin install sparkknife-ledger.zip --activate

# ۳) اگر خوب نبود، برگرد
wp plugin deactivate sparkknife-ledger && wp db import backup.sql
```

بدون SSH: UpdraftPlus برای پشتیبان + بارگذاری ZIP از پنل وردپرس.
