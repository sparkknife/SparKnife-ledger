# رابط گرافیکی لایسنس — بدون خط فرمان

اگر از تایپ دستور خوشتان نمی‌آید، این را استفاده کنید.

---

## باز کردن

**ویندوز:** در پوشهٔ پروژه، `tools\licensing\UI.bat` را دوبار کلیک کنید.

**مک:** `tools/licensing/UI.command` را دوبار کلیک کنید.

مرورگر خودش باز می‌شود و می‌رود روی `http://127.0.0.1:4173`.

> اگر Node.js نصب نیست، پیام می‌دهد و لینک نصب. Node همراه VS Code
> می‌آید، پس احتمالاً دارید. بررسی: در Git Bash بزنید `node -v`.

---

## پنج تب

### ۱) صدور لایسنس

دامنهٔ مشتری را تایپ کنید، دکمه را بزنید. تمام.

خروجی:

- چهار کارت: دامنه، نسخه، انقضا، سریال
- «بررسی خودکار: معتبر است» — با openssl واقعی چک می‌شود، نه باور به
  اینکه خودمان ساختیم
- کلید کامل در یک کادر + دکمهٔ **کپی**
- سه گام برای مشتری

**دامنه:** فقط دامنه. `example.com` بنویسید، نه `https://example.com/`.
اگر `https://` تایپ کنید، برنامه خودش برمی‌دارد.

**بدون انقضا:** تیک بزنید. برای فروش دائمی.

### ۲) بررسی کلید

کلیدی که مشتری فرستاده را بچسبانید. می‌گوید:

- ✓ «امضا معتبر است و کلید هنوز منقضی نشده» — یا
- ✗ «امضا نامعتبر است — کلید جعل شده یا دستکاری شده»
- ✗ «کلید منقضی شده (تاریخ)»

و چهار فیلد کلید.

### ۳) راه‌اندازی

اگر هنوز کلیدی نساخته‌اید، یک دکمه دارد. بزنید، تمام.

اگر ساخته‌اید، اثر انگشت کلید را نشان می‌دهد و دکمهٔ «ساخت کلید تازه»
(با هشدار دومرحله‌ای).

### ۴) انتشار نسخه

نسخه را بالا می‌برد، زیپ می‌سازد، و `release.json` را می‌نویسد.

سپس گام‌های دستی را نشان می‌دهد (git و GitHub Release).

### ۵) راهنما

کلید خصوصی کجا باشد، و به‌روزرسانی خودکار چطور کار می‌کند.

## چه چیزی زیرش اجرا می‌شود

همان `tools/licensing/sparkknife.sh`. رابط گرافیکی فقط یک پوستهٔ
خوانا روی همان اسکریپت است — یعنی **دو منبع حقیقت وجود ندارد**. هر
باگی که در یکی رفع شود، در هر دو رفع است.

سرور روی `127.0.0.1` گوش می‌دهد، نه `0.0.0.0`. از دستگاه دیگری در
شبکه قابل دسترسی نیست. درخواست از هر آدرسی جز خود دستگاه با ۴۰۳ رد
می‌شود.

## اگر باز نشد

| مشکل | علت | راه‌حل |
| --- | --- | --- |
| «Node.js پیدا نشد» | Node نصب نیست | `nodejs.org` |
| صفحهٔ سفید | پورت ۴۱۷۳ اشغال است | `SPK_PORT=5000 node tools/licensing/ui/server.js` |
| «سرور در دسترس نیست» | سرور بسته شده | دوباره `UI.bat` را بزنید |
| خطای openssl | Git ناقص نصب شده | Git for Windows را دوباره نصب کنید |

اگر هیچ‌کدام جواب نداد، همان خط فرمان همیشه کار می‌کند:

```bash
bash tools/licensing/sparkknife.sh key --domain=example.com
```

## امنیت

سرور فقط برای شماست:

- روی `127.0.0.1` می‌شنود، نه شبکه
- درخواست از آدرس غیرمحلی را با ۴۰۳ رد می‌کند
- هیچ داده‌ای بیرون نمی‌فرستد — نه به من، نه به GitHub، نه جای دیگر
- وقتی پنجرهٔ ترمینال را ببندید، سرور خاموش می‌شود

کلید خصوصی خوانده می‌شود ولی **هرگز به مرورگر فرستاده نمی‌شود**.
مرورگر فقط کلید عمومی و نتیجهٔ امضا را می‌بیند.
