## ۱. پشتیبان کلید خصوصی — ۵ دقیقه

### چرا فوری است

جفت کلید ساخته شد و `PUBLIC_KEY` داخل کد با آن هم‌خوان است. ولی
کلید خصوصی **فقط در این ورک‌اسپیس** است. اگر این محیط پاک شود:

- کلید می‌رود
- هر لایسنسی که صادر کرده باشید **باطل** می‌شود
- باید جفت تازه بسازید و به همهٔ خریداران کلید نو بدهید

### انجام

```bash
cat tools/licensing/private_key.pem
```

کل خروجی (شامل `-----BEGIN PRIVATE KEY-----` و `-----END PRIVATE KEY-----`)
را کپی کنید و در **دو** جا بگذارید:

- [ ] گاوصندوق رمز (1Password / Bitwarden / …)
- [ ] یک نسخهٔ آفلاین: USB یا کاغذ چاپ‌شده

### تأیید

```bash
openssl pkey -in tools/licensing/private_key.pem -noout -check
# باید بگوید: Key is valid
```

اثر انگشت درست: `96e14f37a0b6d2ce676cc09ec4b15397aea7e66ed4d730d5deab2d95ee05cfbb`

```bash
openssl rsa -in tools/licensing/private_key.pem -pubout 2>/dev/null | openssl dgst -sha256 -r | awk '{print $1}'
```

اگر این دو یکی نبود، کلید عوض شده — پیش از هر چیز دیگری بگویید.

## ۲. نصب روی سایت واقعی با MySQL — ۱۵ دقیقه

### چرا نمی‌توانستم

محیط توسعه SQLite داشت. افزونه با هر دو کار می‌کند، ولی MySQL
واقعی رفتارهای متفاوتی دارد که فقط روی هاست خودتان دیده می‌شود:
collation فارسی، `utf8mb4`، محدودیت طول ایندکس.

### آماده‌سازی

- [ ] یک **سایت آزمایشی** (نه سایت اصلی). روی تولید نصب نکنید.
- [ ] PHP 7.4 یا بالاتر — پیشنهاد ۸.۱+
- [ ] HTTPS فعال

### نصب

۱. پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه
۲. `sparkknife-ledger.zip` را انتخاب کنید → نصب
۳. **فعال‌سازی**

### چه باید ببینید

- [ ] منوی «دفتر حساب» در نوار کناری
- [ ] ویزارد راه‌اندازی چهارمرحله‌ای
- [ ] پیام «افزونه با موفقیت نصب شد»

اگر منو نیست → `INSTALLATION.md` بخش «منو ظاهر نمی‌شود».

### صفحهٔ سلامت

دفتر حساب → سلامت و امنیت

انتظار: **۷ بررسی**. دو مورد ممکن است `warn` باشند:

| بررسی | چرا warn | کار |
| --- | --- | --- |
| HTTPS | اگر سایت HTTP است | **این را رفع کنید** |
| پیشوند جدول | اگر `wp_` است | بی‌خطر |
| لایسنس | `info` تا کلیدی ندهید | طبیعی |

### آزمون دیتابیس

```bash
php tests/run-tests.php /path/to/wp-load.php
```

انتظار: `همه تست‌ها موفق: ۹۹۰ مورد`

⚠️ **روی سایت تولیدی اجرا نکنید** — آزمون داده می‌سازد و پاک می‌کند.

## آنچه دیگر روی شما نیست

این‌ها همه انجام و آزموده شده‌اند. لازم نیست دوباره بررسی کنید:

**ساختار و داده**
- ساختار دیتابیس و مهاجرت‌ها
- ارتقا از ۱.۰.۰ به ۱.۱.۰ با حفظ داده
- حذف افزونه در دو حالت (حفظ داده / حذف کامل)
- محاسبات مالی و دقت اعشار
- شمسی و میلادی
- ابطال و بازیابی تراکنش

**امنیت**
- ۴۴ پرس‌وجوی SQL (همه prepare)
- ۸ nonce
- ۱۵ capability
- ۱۱ سناریوی تزریق فرمول CSV
- دسترسی نقش‌ها (باگ ۸۶، ۸۷)
- حذف داده بدون مجوز

**سازگاری**
- PHP 7.4، 8.0، 8.1، 8.2، 8.3، 8.4، **8.5** — همه بدون هشدار
- رندر هر ۱۱ صفحهٔ پنل

**فروش**
- جفت کلید ساخته شد
- لایسنس صادر و آزموده شد (معتبر پذیرفته، جعلی رد)
- بسته امضا شد و دست‌کاری را می‌گیرد
- کلید خصوصی در بسته و در گیت نیست

**مستندات**
- نویسندگی هر ۷۷ فایل
- راهنمای نصب، معماری، ممیزی، امضا
