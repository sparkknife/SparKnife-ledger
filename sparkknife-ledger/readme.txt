== Description ==

**SparKnife Ledger** یک افزونه کامل دفتر حساب (Ledger) برای مدیریت حساب اشخاص است. برخلاف افزونه‌های فروشگاهی، این ابزار برای دفترداری واقعی طراحی شده: هر شخص یک مانده دارد، هر تراکنش قابل ابطال است و هر تغییر در تاریخچه ثبت می‌شود.

= برای چه کسانی؟ =

* مدیریت حساب مشتریان، تأمین‌کنندگان و همکاران
* ثبت دریافت و پرداخت با مانده‌گیری لحظه‌ای
* گزارش‌گیری از گردش حساب یک شخص یا همه اشخاص
* کسب‌وکارهایی که با تومان/ریال و تقویم شمسی کار می‌کنند

= امکانات =

* **مدیریت اشخاص** — افزودن، ویرایش، غیرفعال‌سازی و حذف نرم (بازگردانی‌پذیر) با جلوگیری از نام تکراری
* **تراکنش‌های ورودی و خروجی** — ثبت دریافت/پرداخت با شماره سند یکتا، تاریخ شمسی یا میلادی، و توضیحات
* **مانده لحظه‌ای** — محاسبه خودکار مانده هر شخص و وضعیت حساب (بدهکار/بستانکار/تسویه)
* **ابطال تراکنش** — تراکنش باطل‌شده حذف نمی‌شود؛ از محاسبات خارج شده و دلیل ابطال ثبت می‌گردد
* **گزارش فردی و تجمیعی** — فیلتر بر اساس بازه تاریخ، نوع تراکنش، وضعیت و شخص؛ همراه با صفحه‌بندی و مرتب‌سازی
* **تاریخچه تغییرات** — ثبت تمام تغییرات با زنجیره هش برای تشخیص دستکاری سوابق
* **خروجی CSV** — سازگار با Excel و با پشتیبانی از ارقام فارسی
* **نمایش چاپ / PDF** — چیدمان چاپی راست‌به‌چپ و آماده ذخیره به PDF از مرورگر
* **تقویم شمسی** — تبدیل و اعتبارسنجی تاریخ جلالی، با امکان انتخاب تقویم میلادی
* **واحد پول قابل تنظیم** — تومان، ریال یا واحد دلخواه با نماد و تعداد اعشار سفارشی
* **ارقام فارسی** — نمایش و پذیرش اعداد فارسی (۱۲۳ و ۱۲۳٬۴۵۶) به‌صورت خودکار
* **دسترسی‌های تفکیک‌شده** — هفت Capability مستقل با ماتریس نقش قابل تنظیم
* **حذف امن** — به‌صورت پیش‌فرض داده‌ها هنگام حذف افزونه حفظ می‌شوند

= محاسبات مالی دقیق =

مبالغ به‌صورت عدد صحیح مقیاس‌شده (مبلغ × ۱۰⁴) در ستون `BIGINT` ذخیره می‌شوند. این روش خطای گرد کردن اعشاری متغیرهای اعشاری (float) را حذف می‌کند و جمع‌های بزرگ را دقیق نگه می‌دارد.

= حریم خصوصی =

افزونه هیچ داده‌ای به بیرون ارسال نمی‌کند. هیچ درخواست HTTP خارجی، ردیاب یا سرویس تحلیلی ندارد. همه داده‌ها در دیتابیس همان سایت شما باقی می‌ماند.

== Installation ==

1. فایل ZIP افزونه را از مسیر **افزونه‌ها ← افزودن ← بارگذاری افزونه** نصب و فعال کنید، یا پوشه `sparkknife-ledger` را در `wp-content/plugins/` قرار دهید.
2. پس از فعال‌سازی، منوی **دفتر حساب** در پنل مدیریت ظاهر می‌شود.
3. برای شروع، یک شخص بسازید (**دفتر حساب ← اشخاص**) و سپس اولین تراکنش را ثبت کنید.
4. در **دفتر حساب ← تنظیمات** واحد پول، تقویم و تعداد آیتم در هر صفحه را تنظیم کنید.

نصب نیازی به هیچ افزونه کمکی، Composer یا تنظیمات فایل ندارد.

= پیش‌نیازها =

* WordPress 5.8 یا بالاتر
* PHP 7.4 یا بالاتر (سازگار با PHP 8.x)
* MySQL 5.7+ / MariaDB 10.3+ (یا درایور SQLite رسمی وردپرس)

= دسترسی‌ها =

در زمان فعال‌سازی، هر هفت Capability به نقش `administrator` اضافه می‌شود. از تب **تنظیمات ← دسترسی‌ها** می‌توانید آن‌ها را به نقش‌های دیگر هم بدهید:

| Capability | کاربرد |
| --- | --- |
| `sparkknife_ledger_manage_persons` | مدیریت اشخاص |
| `sparkknife_ledger_manage_transactions` | ثبت و ویرایش تراکنش |
| `sparkknife_ledger_void_transactions` | ابطال تراکنش |
| `sparkknife_ledger_reports` | مشاهده داشبورد و گزارش‌ها |
| `sparkknife_ledger_export_reports` | خروجی گرفتن از گزارش‌ها |
| `sparkknife_ledger_view_audit` | مشاهده تاریخچه تغییرات |
| `sparkknife_ledger_manage_settings` | مدیریت تنظیمات افزونه |

== Frequently Asked Questions ==

= آیا با حذف افزونه، داده‌های مالی پاک می‌شوند؟ =

خیر. به‌صورت پیش‌فرض جداول، تراکنش‌ها، تنظیمات و دسترسی‌ها هنگام حذف افزونه دست‌نخورده می‌مانند. اگر می‌خواهید با حذف افزونه همه‌چیز پاک شود، گزینه **حذف داده‌ها هنگام حذف افزونه** را در تنظیمات روشن کنید. برای پاک‌سازی دستی، دکمه **حذف کامل داده‌ها** در تب تنظیمات ← داده‌ها در دسترس است.

= تراکنش اشتباه را چطور اصلاح کنم؟ =

دو راه دارید. اگر فقط جزئیات اشتباه است، تراکنش را ویرایش کنید. اگر تراکنش نباید در حساب باشد، آن را **ابطال** کنید — تاریخچه حفظ می‌شود و مبلغ از مانده خارج می‌گردد. حذف فیزیکی تراکنش وجود ندارد تا سوابق حسابداری دستکاری‌نشدنی بماند.

= پشتیبانی از تقویم شمسی چقدر کامل است؟ =

تبدیل دوطرفه شمسی/میلادی، اعتبارسنجی کامل (شامل کبیسه بودن سال شمسی) و نمایش با ارقام فارسی. تقویم پیش‌فرض شمسی است؛ از تنظیمات می‌توانید میلادی را انتخاب کنید.

= آیا ارقام فارسی هنگام ورود پذیرفته می‌شوند؟ =

بله. `۱۲۳`, `۱۲۳٬۴۵۶` و `1,250,000` همگی به یک مقدار عددی تبدیل می‌شوند.

= خروجی Excel واقعی (xlsx) دارد؟ =

خروجی فعلی CSV با BOM است که Excel آن را درست باز می‌کند. برای xlsx واقعی، هوک `sparkknife_ledger_export_formats` برای افزودن فرمت جدید مهیا است.

= با وردپرس چندسایتی کار می‌کند؟ =

بله. در حالت چندسایتی، هر سایت جداول و تنظیمات خودش را دارد و عملیات حذف برای همه سایت‌ها اعمال می‌شود.
